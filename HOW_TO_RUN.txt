RUNNING THE AGENT SYSTEM
========================

TERMINAL (CLI)
--------------
.venv\Scripts\python.exe main.py          (Windows)
.venv/bin/python main.py                  (macOS / Linux)

Type your request and press Enter. Type q to quit.


UI (Gradio web interface)
-------------------------
.venv\Scripts\python.exe run_ui.py        (Windows)
.venv/bin/python run_ui.py                (macOS / Linux)

Then open http://127.0.0.1:7860 in your browser.


CHANGING PROVIDERS
------------------
Copy .env.example to .env and set MODEL_PROVIDER to one of:

  azure   — Azure OpenAI (requires AZURE_OPENAI_API_KEY, AZURE_OPENAI_ENDPOINT,
             AZURE_OPENAI_API_VERSION, AZURE_OPENAI_DEPLOYMENT, AZURE_OPENAI_EMBEDDING)

  openai  — OpenAI (requires OPENAI_API_KEY; optionally set OPENAI_MODEL and
             OPENAI_EMBEDDING to override defaults)

  ollama  — Local Ollama (requires Ollama running at OLLAMA_BASE_URL;
             set OLLAMA_MODEL and OLLAMA_EMBEDDINGS to match your pulled models)

Optional API tool keys (leave blank to disable those tools):
  POSITIONSTACK_API_KEY  — geolocation
  NEWSDATA_API_KEY       — news search
  TAVILY_API_KEY         — web search
